# Anagbuo Kingsley — CV and portfolio

A static personal website using the biographical information already in this repository.

## Use

Open `index.html` in a browser. No build step or dependency installation is needed. The optional **Print / save PDF** button opens the browser print dialog. Choose A4 paper, turn off browser headers/footers, and inspect the resulting pages.

## Structure

- `index.html`: profile, education, selected project, skills, and additional experience.
- `contact.html`: GitHub profile and repository links.
- `styles.css`: responsive layout, keyboard focus styles, and A4 print styles.
- `print.js`: optional print button; content remains readable without JavaScript.

The original `kings.png` asset is retained but unused.

## Maintenance

Keep experience in reverse chronological order. Describe skills with demonstrable work rather than star ratings. Check current evidence before reintroducing earlier company claims or contact details.

For applications, maintain a separate CV tailored to each programme's requirements. Keep sensitive application records and referee contact details outside this public repository.
